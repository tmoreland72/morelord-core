# Morelord Core 0.4.0

## What Changed

### Added

- Shared keyboard-accessible tabs, quantity controls, inline actor portrait selectors, responsive layouts, and collapsible sidebars support Marketplace's new Transfer workflow.

### Fixed

- Wide inventory tables keep horizontal scrolling within the shared page layout, and long item links wrap inside cards.

## Compatibility and verification

Verified on Foundry VTT 14.368 with D&D5e 6.0.3 in Dev1. Existing support bounds are unchanged. Core's 68 automated checks, Marketplace's 32 checks, Craftworks' 71 checks, and the shared design-system check passed. Live checks cover GM/player routing, shared controls, narrow layouts, and both themes.
