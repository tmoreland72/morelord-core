# Morelord Core 0.6.1

## What Changed

### Changed

- **Morelord Tools** lists its tools alphabetically by title, ignoring capitalization. A module's order value no longer changes the sequence. With the titles Craftworks, Downtime, Encounters, Journeys, Manage Shops, and Marketplace, that is the palette order.
- **Morelord Modules**, the info entry at the top of **Morelord Tools**, opens a window of the same name for GMs and players. It lists Core, Journeys, Encounters, Character Export, Craftworks, Marketplace, Downtime, and Game Master, each with its icon, one-line description, and a live status of **Active**, **Installed but inactive**, or **Not installed**. **Documentation** opens that module's guide. **Learn more** on a module that is **Not installed** opens that module's tools page. Game Master has no guide or tools page, so it has no **Documentation** link and **Learn more** opens its GitHub repository. **Support** offers **Get support** for the Morelord Discord server, **Morelord Gaming** for the website, and **YouTube** for the channel. Choosing the crown still only shows the tool column. The entry stays selected so choosing the crown does not open another window.
