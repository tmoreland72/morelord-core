# Morelord Core 0.6.1

## What Changed

### Changed

- **Morelord Tools** lists its tools alphabetically by title, ignoring capitalization and a leading Morelord prefix. The button labels stay as registered. A module's order value no longer changes the sequence. With the titles Morelord Craftworks, Morelord Downtime, Morelord Encounters, Morelord Journeys, Manage Marketplace Shops, and Morelord Marketplace, that is the palette order.
- **Morelord Modules**, the info entry at the top of **Morelord Tools**, is shown only to a GM and opens a window of the same name. Players do not see that entry, and the window does not open for them. Players still see the other Morelord tools, including Morelord Craftworks, Morelord Downtime, and Morelord Marketplace. Choosing the crown only shows the tool column, and choosing a tool leaves **Morelord Tools** selected. The window lists Core, Journeys, Encounters, Character Export, Craftworks, Marketplace, Downtime, and Game Master, each with its icon, one-line description, and a live status of **Active**, **Installed but inactive**, or **Not installed**. **Documentation** opens the documentation index at morelordgaming.com/docs. **Learn more** on a module that is **Not installed** opens that module's tools page. Game Master has no tools page, so **Learn more** opens its GitHub repository. **Support** offers **Get support** for the Morelord Discord server, **Morelord Gaming** for the website, and **YouTube** for the channel.
