# Morelord Core 0.6.1

## What Changed

### Changed

- **Morelord Tools** lists its tools alphabetically by title, ignoring capitalization. A module's order value no longer changes the sequence. With the titles Craftworks, Downtime, Encounters, Journeys, Manage Shops, and Marketplace, that is the palette order.
- **Overview**, the info entry at the top of **Morelord Tools**, opens a dialog titled **Morelord Tools**. The dialog lists the tools available to the current user, with a short description when the module provided one. **Close** dismisses it. Choosing the crown still only shows the tool column. The entry stays because Foundry 13 cannot switch to this control without a selected tool that is not a button, and selecting a module tool for that would open the tool when the crown is clicked.
