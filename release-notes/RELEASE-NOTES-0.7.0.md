# Morelord Core 0.7.0

## What Changed

### Added

- Right-click a hotbar macro for **Run on load for me** or, as a GM, **Run on load for everyone**. Each entry switches to **Running on load for me** or **Running on load for everyone** while it is on, and choosing it again turns it off. The user choice runs only for that user. The everyone choice runs for each user who loads the world, and players do not see it. A macro marked both ways runs once. Macros the user cannot see or execute are skipped, and one failure does not stop the others. A user icon (**Runs on load for you**) and a group icon (**Runs on load for everyone**) mark the right side of the slot.
