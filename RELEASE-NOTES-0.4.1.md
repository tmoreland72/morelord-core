# Morelord Core 0.4.1

## What Changed

### Added

- Shared window opacity control allows Morelord Game Master to use a fully opaque panel and tray handle. Other windows retain their existing appearance.

## Compatibility and verification

Verified on Foundry VTT 14.368 with D&D5e 6.0.3 in Dev1. Core's 68 automated checks and the design-system check passed. Game Master's panel regression and Core smoke checks passed at 1280×850, 1920×1080, and 700×600, covering viewport sizing, stacking above other windows, and opaque panel/handle backgrounds.
